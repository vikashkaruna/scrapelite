DatIQ Extension — Options

How to use

  1. Sign in to datiq.app on a Business or Enterprise plan.
  2. Go to Account → API keys and create a new key.
  3. Click the DatIQ icon in your browser toolbar, paste the key, click Save & connect.
  4. Right-click any page → Extract this page with DatIQ.

Send extractions anywhere

Once extracted, your page lands in the DatIQ dashboard. From there it can be sent to:

  • HubSpot (contacts & companies)
  • Notion (database rows)
  • Airtable (records)
  • Slack (channel notifications)
  • Zapier (5,000+ apps)

See docs/integrations for setup steps.

Troubleshooting

If right-click doesn't show the DatIQ option:

  • Reload the page after installing the extension.
  • Check the extension is enabled at chrome://extensions/.
  • Open the service worker console (also on the extensions page) for errors.
