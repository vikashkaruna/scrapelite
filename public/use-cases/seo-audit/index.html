Why DatIQ for SEO audits

Most SEO tools assume you're doing a 10,000-page crawl. For most teams, that's not the question — the question is "what is this page missing, and what does the competitor's version do better?" DatIQ is built for that.

H1→H6 in document order

One paste, every heading on the page. The DatIQ preview shows hierarchy, missing levels (e.g. H1→H3 with no H2), and lets you click any heading to copy.

Internal and external link profile

Every link, classified by AI: navigation, content, call-to-action, social, etc. Filter to find orphan pages (no internal links in) or under-linked key pages.

JSON-LD and schema check

Default extraction returns any structured data on the page. Use a custom prompt: "Extract every JSON-LD block with @type. Flag any required schema.org field that is missing."

Full domain map

"Map entire domain" routes to Firecrawl's /map endpoint and returns every crawlable URL on the site. Then batch-extract them on Pro and above.

Competitor content gaps

Compare two URLs in the Compare content format. DatIQ returns a side-by-side of headings, FAQ presence, word count, and topic coverage. Useful for content gap analysis.

CSV / Sheets export

Every audit is one CSV export. Columns for URL, H1, H2 count, internal link count, external link count, schema presence, AI summary. Pivot in your spreadsheet of choice.

Step-by-step: audit any page in 4 steps

Step 1

Paste the URL

Drop any URL into the composer. Render JavaScript is on by default so SPAs work.

Step 2

Read the structure

The preview shows headings, links (with filter chips), meta tags, and an AI summary. The dashboard is the audit.

Step 3

Map the domain (optional)

Toggle "Map entire domain" to see every crawlable URL on the site. Pick the 10-50 that matter for your audit.

Step 4

Export and act

CSV for analysis, Google Sheets for sharing, PDF for the deck. Schedule a re-audit to catch regressions.

Tips from the field

Tip 1. For a content gap analysis, paste your URL and the competitor's URL, then use the Compare content format. DatIQ returns a side-by-side of headings, FAQ presence, and topic coverage.
Tip 2. For a fast schema audit, use the custom prompt: "For every JSON-LD block on this page, list the @type, then check each one against schema.org required fields. Flag missing fields as a list of {type, missing_field}."
Tip 3. Internal link audits: extract the page, filter the links list to "Internal", and look for orphan pages (no inbound links) or over-linked navigation (more than 20% of internal links).
Tip 4. Schedule a re-audit monthly (Pro+). The diff view shows new pages, removed pages, and content changes — useful for catching accidental template changes or unintended content removals.

Common questions

How do I audit a website's SEO with DatIQ?

Paste any URL. The default extraction returns headings, links, meta tags, schema, and an AI summary. Enable "Map entire domain" for full-site coverage.

Can DatIQ find missing schema markup?

Yes — use a custom prompt asking for every JSON-LD @type and required field. DatIQ returns a structured gap report per page.

How do I audit an entire domain?

Toggle "Map entire domain" to get the full URL list, then batch-extract on Pro and above. One CSV export covers the whole site.

Can DatIQ replace Screaming Frog or Sitebulb?

For most small-to-medium sites, yes — DatIQ is faster to set up and cheaper. For very large sites (10K+ URLs), a desktop crawler like Screaming Frog is more efficient. Use both as needed.
