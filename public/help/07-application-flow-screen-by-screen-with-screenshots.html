App walkthrough — screens & features

Every screen in DatIQ explained, from the URL input to multi-URL batch extraction and your saved archive.

The core loop: paste a URL on the Home screen → review and enrich on Preview → save to Dashboard → export, share, or generate content. For multiple URLs at once, use the Batch screen.

Dashboard/dashboardYour saved archive — search, filter, export, generate

Home — Extract (route /)

The entry point. Paste any public URL, pick what you want to extract, and press Extract.

What's on the page

  1. URL field — a globe-icon input. Paste any URL, including bare domains like stripe.com. An inline error appears for invalid input.
  2. Extract button — starts the extraction. While running, a full-screen 4-step loader is shown.
  3. Bulk import button — a small button next to Extract labelled "Bulk import". Click it to go to the Batch screen where you can enter multiple URLs at once.
  4. Intent chips — five chips that set what kind of data you want:
    • AI summary — page overview, headings, link structure, and AI-generated paragraph summary (default).
    • Find contacts — leadership names, emails, LinkedIn profiles, and board members.
    • Scrape pricing — pricing tiers, plan names, and feature lists.
    • Map site — lists every indexed URL on a domain (uses the full-domain crawl endpoint). Tip: enter just the domain root, e.g. notion.so.
    • Custom — reveals a text box where you can type your own extraction prompt in plain English.
  5. Capability cards — eight clickable cards describing what DatIQ can do. Clicking a card switches to the matching intent chip.

After extraction

DatIQ automatically saves the result and navigates to the Preview screen. If the extraction fails, an error modal appears with a Try again button.

Preview — Review & Enrich (route /preview)

Review the raw extraction, run AI enrichments, and decide what to do with the result.

Action bar

  • View Dashboard (primary) — navigates to your saved archive. The extraction is already saved automatically.
  • Download ▾ — dropdown with four formats: CSV, PDF, Markdown, JSON.
  • Delete — removes this extraction and returns to Home.

Page content

  1. Page identity — favicon, title, URL (clickable), heading count, and link count.
  2. AI summary card — a generated paragraph overview, badged "AI". The card also has a Generate content button that opens the content generation modal (SEO outline, competitor summary, or social posts).
  3. Quick enrichment panel — five buttons: Contacts, Leadership & Board, Pricing & Plans, Social Links, Company Mission. Each runs in the background; a ✓ badge appears when done. Clicking a ✓ badge refreshes it.
  4. Tabs — Overview plus one tab per completed enrichment. Overview shows headings and categorised links side-by-side. Enrichment tabs show structured data (e.g. a contacts table or pricing comparison).

Map-mode variant: when you extracted with the Map site intent chip, the Overview tab shows a full searchable list of every discovered URL on the domain instead of per-page structure. Quick enrichment is hidden in this mode.

Dashboard — Saved archive (route /dashboard)

Your searchable history of every saved extraction. Use it to export data, generate content, or send results by email.

Header actions

  • Table / Card toggle — switch between a data table and a card grid. Your preference is remembered.
  • Batch runs ▾ — a dropdown listing every past multi-URL batch run. Click a run to filter the table to only show pages from that batch. Each item has a "Batch" tag chip in the table so you can see at a glance which rows came from a bulk run.
  • Export ▾ — download all (or selected) results as CSV, PDF, Markdown, or JSON. Visible only when you have saved extractions.
  • Refresh — re-fetch your latest extractions from the server.
  • New extraction — returns to Home.

Table & selection

Columns: select checkbox, Page (favicon + title + domain), AI summary snippet, Structure (headings & links count), Extracted date, and row-level View / Delete actions.

Ticking one or more checkboxes reveals:

  • An inline toolbar with Generate, Email, and Clear buttons.
  • A floating bar at the bottom of the screen with the same actions plus an Export ▾ dropdown for the selection only.

Generate opens a modal to create AI-written content (SEO Blog Outline / Competitor Summary / Social Posts) from the selected page.

Email opens a modal to send selected extractions to one or more recipients.

Search

The search box matches across title, URL, AI summary, headings, and links simultaneously.

Batch — Multi-URL extraction (route /batch)

Extract 10–500 URLs in a single run. Navigate here by clicking Bulk import on the Home screen.

Input methods

  • Paste URLs tab — paste one URL per line into the text area. Your draft is automatically saved in the browser; if you leave and come back, the URLs are still there. Click New batch to clear the draft and start fresh.
  • Import CSV tab — upload a CSV file; DatIQ reads the first column (or any column containing URLs) automatically.

Intent chips

Same as Home: AI summary / Find contacts / Scrape pricing / Custom. Select the intent before running so all pages are extracted consistently.

Run & results

Click Run batch. A progress bar shows completed / total. Each URL is extracted with up to three concurrent requests. When finished:

  • A results table lists every URL — green dot for success, red dot for failure — with an AI summary snippet per row and a View button that opens that page in Preview.
  • Successful results are automatically saved to your Dashboard.
  • The Export ▾ dropdown lets you download all results as CSV, PDF, Markdown, or JSON.
  • A View in Dashboard → button appears to jump straight to your filtered archive.

Navigation bar

Persistent across all screens (except Admin).

  • DatIQ logo — clicks back to Home.
  • Extract / Batch / Dashboard — main navigation links.
  • Explore ▾ — dropdown with Use Cases, Compare tools, Resources (Blog, Help Center), and Contact.
  • Sign in / Sign up — when not logged in.
  • User menu ▾ — when logged in: your persona name, Account & Usage link, Switch Role, Sign out.
  • Theme toggle (sun/moon icon) — switches between light and dark mode. Preference is saved.

On mobile (<600px) the nav collapses to a hamburger menu.
