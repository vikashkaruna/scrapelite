To regenerate, run the dev server and capture each route. Stateful screens (Preview, Dashboard) need seeded data; the simplest method is a localStorage-only dev instance plus a small seed page that sets scrapelite.saved / scrapelite.current and then redirects into the route.

15.2 Environment variables

VariablePurpose
VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEYCloud persistence (optional).
VITE_FIRECRAWL_API_KEYReal scraping & domain mapping.
VITE_AI_API_KEY / VITE_AI_MODELReal Claude summaries, categorization, content.
VITE_WEBHOOK_URLSave notifications (n8n).
VITE_EMAIL_API_URLEmail delivery endpoint.

Absent any of these, the corresponding feature uses its mock/fallback path.

15.3 Run locally

npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
