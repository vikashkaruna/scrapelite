Section 4

Exports & sharing

Every format you need to get your extracted data out of DatIQ — and into spreadsheets, reports, or your team's inbox.

Export scope rule: if you have rows selected in the Dashboard, all exports use the selection. If nothing is selected, exports cover everything currently matching your search filter.

Export formats

Format Best for What's included Plan required
CSV Spreadsheets, CRM import, data analysis All metadata, headings, links, and enrichment data — each field in its own column. If a page has enrichment data, all enriched fields are included. All plans (including Free)
PDF Reports, presentations, sharing with stakeholders Formatted report with the same content as the CSV — one page per extraction. Includes AI summary, headings, links, and enrichment data. All plans (including Free)
Markdown Developer documentation, Notion/Obsidian, CMS import Clean Markdown document with headings, bullet lists for links, and enrichment data as formatted sections. Easy to paste into any Markdown editor. Select plan and above
JSON Developers, API integrations, data pipelines Full structured JSON array — one object per extraction, including all metadata and enrichment fields. Ideal for programmatic processing. Pro plan and above
Email Sharing results with colleagues or clients Title, URL, AI summary, and key counts per page. Recipients receive a clean email digest — no account needed to read it. Select plan and above

Where to export from

Export buttons appear in two places:

  • Dashboard → Export ▾ dropdown — single button in the Dashboard header. Click to show the CSV / PDF / Markdown / JSON options. If rows are selected, only those rows are exported.
  • Preview page → Download ▾ dropdown — available in the action bar when viewing a single extraction. Exports just that extraction.
  • Batch results page — after a batch extraction completes, export all successful results with the same format options.
  • Floating selection bar — when one or more rows are selected in the Dashboard, a bar appears at the bottom of the screen with an Export dropdown for the selection.

Email export

The email export lets you send a summary of selected extractions to any email address. To use it:

  1. Select one or more rows in the Dashboard.
  2. Click Email in the toolbar or the floating selection bar.
  3. Enter recipient email addresses (comma-separated for multiple).
  4. Click Send.

Each recipient receives a clean summary email with the page title, URL, AI summary, and key stats for each extraction. No DatIQ account is required to read the email.

Tips

  • Use the Dashboard search bar to filter down to a subset before exporting — the export will only include matching rows if nothing is explicitly selected.
  • For large exports, CSV is the fastest format. PDF generation is done on-demand and may take a few seconds for many pages.
  • If the page shows an "App updated" toast when you try PDF export, refresh the page first — this happens when a new version was deployed since you opened the tab.
  • Markdown export is ideal for feeding extracted content into AI tools, documentation systems, or static site generators.
  • JSON export preserves all nested enrichment data exactly — best choice when you need to process results programmatically.
