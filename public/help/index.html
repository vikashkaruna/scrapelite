DatIQ — Help & Documentation

Everything DatIQ can do — features, screens, and workflows. Building an integration? See the developer API reference.

Audience: everyone who uses DatIQ — analysts, marketers, founders, researchers, and sales teams.
This guide explains what DatIQ does and how to use it. It is written for people, not engineers:
there are no code samples, database details, or setup instructions here. If you build software and
want to call DatIQ programmatically, see the separate Developer API reference.

DatIQ — The Unified Web Intelligence Platform. DatIQ turns any public web page into structured, usable data — headings, links, contacts, pricing, and a plain-language AI summary — in seconds. No code, no browser extensions, no scrapers to configure. Paste a URL (or many), choose what you want, and DatIQ does the rest. The whole platform is built on Pillar 0 — Web Intelligence (Core), the proven single, batch, and scheduled URL-extraction engine.
